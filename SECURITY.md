# Security policy

SailFactor holds the second factor of logins, so I take reports seriously.
Please don't open a public issue for a security problem.

## Reporting a vulnerability

[Report it privately on GitHub](https://github.com/tordenskjoldsw/harbour-sailfactor/security/advisories/new).

Include the SailFactor version (shown on the About page), the Sailfish OS
version, the steps to reproduce and what an attacker gains. Use a test
file and made-up secrets: never send me a real TOTP secret, a real QR code
or a real database.

I confirm that your report arrived, keep you posted while I work on a fix,
and credit you in the release notes unless you would rather stay anonymous.

## Supported versions

Only the latest release gets security fixes. There is no release yet.
