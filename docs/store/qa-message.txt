SailToken needs no account. To try it, choose "Create file" on the first page (the master password needs at least 15 characters), then pull down and choose "Type in an account". The secret JBSWY3DPEHPK3PXP with any issuer gives a working test account; "Scan QR code" reads a QR code with the URI otpauth://totp/Example:test?secret=JBSWY3DPEHPK3PXP&issuer=Example shown on another screen.

Permissions: Camera is used only on the scan page to read QR codes; frames are processed on the phone and never stored. Documents and Downloads are used to add an existing .kdbx file and its key file, merge a copy and save a copy, always files the user picks or names. Internet is used only for the optional Nextcloud sync (Settings > Sync with Nextcloud), which needs the user's own Nextcloud server; the app works fully without it. The sync login opens the Nextcloud login page in the browser (Nextcloud Login Flow v2).

Test files with fake data are in the repository under core/tests/fixtures (password: sailvault-fixture); totp-entries.kdbx has one account for every way KeePassXC stores TOTP settings.
